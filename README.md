# FIFAR – Friends in Football at Risborough

Flat-HTML rebuild of fifar.org.uk (content recovered from the January 2025 Wayback Machine snapshot) with a modern football design.

- No build step: plain HTML, `css/style.css`, `js/main.js`
- Post pages live in `news/`
- Recovered images and PDFs are in `img/uploads/`
- Deployed on Vercel
